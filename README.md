# ClipSync

Windows と iPhone の間でクリップボードをリアルタイムに同期する小さなツールです。テキスト・画像・任意のファイルに対応し、ローカルネットワーク経由で直接転送するほか、APNs プッシュ通知でバックグラウンドの iOS 端末を起こすこともできます。

## アーキテクチャ

プロジェクトは 2 つのコンポーネントで構成されています。

```
Windows（トレイ常駐アプリ、内蔵 HTTP/WebSocket サーバー）
   │  クリップボードの変化を監視
   ▼
クリップボード変更 ──► APNs へプッシュ ──► iPhone（Shortcuts / ネイティブアプリ）
                                                  │
                              プッシュ受信後、Windows サーバーから最新の内容を取得

```

| コンポーネント          | パス                                                         | 説明                                                                                                                                                   |
| ----------------------- | ------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **ClipSync.WindowsApp** | [src/ClipSync.WindowsApp](src/ClipSync.WindowsApp)           | Windows のシステムトレイ常駐アプリ。ASP.NET Core (Kestrel) サーバーを内蔵し、クリップボードの監視・提供、ペアリング、プッシュ通知のトリガーを担当。    |
| **ClipSync.iOSApp**     | [src/ClipSync.iOSApp/clipsync](src/ClipSync.iOSApp/clipsync) | Xcode プロジェクト。設定と動作確認用のネイティブ SwiftUI アプリを含むが、メインのクライアントは Apple Shortcuts と組み合わせて使う想定。現状は保留中。 |

## 主な機能

- **QR コードによるワンタップペアリング**：トレイメニューから QR コードを表示でき、サーバー URL とキーを含む。Shortcuts でスキャンするだけで設定完了。
- **テキスト / 画像 / 任意のファイル**：クリップボードの内容は常に生のバイト列（raw bytes）で転送し、Base64 や JSON でラップしない。拡張子から MIME タイプを判定。
- **2 系統のリアルタイム通知**：同一 LAN 内では WebSocket で変更を通知。LAN 外やアプリがバックグラウンドの場合は APNs のサイレントプッシュで起床させる。
- **キー認証**：すべての API 呼び出しは `X-ClipSync-Key` ヘッダーで認証される。キーは初回起動時に自動生成される。

## 開発環境

- .NET SDK（`net10.0` / `net10.0-windows`。`dotnet --version` で確認可能）
- Windows 側は WinForms を使用するため Windows 上での実行が必須
- iOS 側は Xcode が必要。プッシュ通知の動作確認には実機が必要（シミュレーターは APNs 非対応）

## クイックスタート

### 1. Windows 側（クリップボードサーバー）

```bash
dotnet run --project src/ClipSync.WindowsApp
```

初回起動時に `%AppData%\ClipSync\config.json` が自動生成され、ランダムなペアリングキーも作成されます。デフォルトのリッスンポートは `913` です。アプリはシステムトレイに常駐し、以下のメニューを提供します。

- 「ペアリング QR コードを表示」：Shortcuts などでスキャンしてペアリング
- 「ペアリングキーをコピー」：サーバー URL / キーを手動でコピー
- 「設定を再読み込み」：設定ファイルを変更した後に反映

主な API：

| メソッド | パス                | 説明                                                                                                                                       |
| -------- | ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| `POST`   | `/clipboard`        | テキストまたはファイルをアップロード（生のバイト列。ファイルの場合は `X-Content-Type: file`、`X-File-Name`、`X-Extension` ヘッダーを付与） |
| `GET`    | `/clipboard/meta`   | 現在のクリップボードのメタ情報（種類・ファイル名・MIME・更新日時）を取得                                                                   |
| `GET`    | `/clipboard/data`   | 現在のクリップボードの実体（生のバイト列）を取得                                                                                           |
| `POST`   | `/devices/register` | iOS デバイスのプッシュ通知トークンを登録                                                                                                   |
| `GET`    | `/ws`               | 内容変更を通知する WebSocket                                                                                                               |

### 2. iPhone 側（Shortcuts）

実際の送受信はこの Shortcuts ショートカットで行います。

- ダウンロード: <https://www.icloud.com/shortcuts/9f1789c0cf96416cbe244b88ab91e98b>
- 上記リンクを iPhone の Safari で開き、「ショートカットを追加」をタップして自分の Shortcuts に保存する

## 使い方

1. Windows 側のアプリを起動しておく(システムトレイに常駐する)
2. iPhone で保存したショートカットを初めて実行すると QR コードのスキャンを求められるので、Windows のトレイメニューから「ペアリング QR コードを表示」を開いてスキャンする(サーバー URL とキーが自動保存され、以降は不要)
3. ショートカットはループ処理になっており、実行中は数秒おきに双方のクリップボードを比較して自動的に同期する
   - Windows でコピーした内容(テキスト・画像・任意のファイル)が iPhone 側に反映される
   - iPhone でコピーした内容も同様に Windows 側に反映される
4. 同期を止めたいときは、実行中の画面に表示されている停止ボタンをタップしてショートカットを終了する
5. iPhone から送ったファイルは、iOS のクリップボードが元のファイル名を保持しないため、`clipboard.<拡張子>` という名前で Windows 側に届く
